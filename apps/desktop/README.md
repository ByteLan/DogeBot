# @dogebot/desktop

`@dogebot/desktop` 是 DogeBot 的 Electron 桌面客户端。它连接 `@dogebot/server`，用于登录服务端并管理当前用户绑定的飞书机器人。

## 主要能力

- 填写服务端 URL、用户名、密码登录。
- 保存服务端 URL 和登录 token 到本地 `localStorage`。
- 查询当前用户绑定的飞书 bot。
- 展示每个 bot 的服务端长连接状态。
- 手动创建新的飞书 bot 绑定。
- 通过扫码创建新的飞书机器人并自动绑定。
- 探测 bot 凭证是否有效。
- 删除当前用户的 bot 绑定。
- 展示每个 bot 的 webhook 兜底地址。
- 监听并同步抖音收藏列表，支持多个活跃任务按顺序执行。

## 开发命令

```bash
pnpm install
pnpm dev
```

安装依赖并启动 Electron 客户端。

```bash
pnpm build
```

编译 Electron 主进程，并通过 Vite 将 React 前端打包为 `dist/index.html` 和 `dist/assets/*`。

## 使用方式

先启动服务端：

```bash
cd ../server
pnpm dev
```

再启动桌面客户端：

```bash
cd ../desktop
pnpm dev
```

客户端启动后填写：

- 服务端 URL：默认 `http://127.0.0.1:3000`。
- 用户名：通过服务端 `pnpm add-user` 创建。
- 密码：创建用户时设置的密码。

登录成功后，可以在页面中绑定飞书 bot。

## 设置

左侧导航的「设置」位于「抖音监控」下方，修改后自动保存，仅对当前设备生效。

- **常规 / 开机自启**：默认关闭。Windows、macOS 安装版通过 Electron 的系统登录项 API 设置，界面读取系统实际状态；开发模式和其他系统禁用该开关，不注册开发版 Electron。macOS 若需要系统批准，页面会提示到系统设置中允许。
- **聊天 / 自己发出的消息气泡**：默认右侧，可切换为左侧；群聊和话题即时生效，操作与时间始终位于气泡另一侧。偏好保存于本地 `dogebot.ownMessageAlignment`，切换不会重建聊天缓存或清除草稿。
- **聊天 / 消息收取方式**：默认「始终收取」，切换页面或隐藏窗口后继续收取。选择「仅查看群聊时收取」后，仅群聊 Tab 被选中且主窗口显示、未最小化时订阅；离开、隐藏到托盘或最小化到 Dock 会暂停，窗口失焦不暂停。新增「从不自动收取」后，不连接实时通道、不因切页或换群自动查询，只在手动刷新时读取。偏好保存于 `dogebot.chatReceiveMode`。

按需模式暂停时保留当前群、话题、内存缓存、草稿、引用和附件，并让已经提交的发送、上传、撤回继续完成；停止后台只读请求与重连。返回后主动校准当前会话与话题；正在阅读旧历史时保留位置，通过各自的「查看最新」入口同步，不假装已经补齐全部历史。暂停期间没有实时新消息提示，红点与新消息提示不代表飞书个人账号的精确未读数。server 的飞书长连接与机器人业务始终独立运行。

手动模式先刷新群列表，选择群仅展示内存缓存，再点击会话或话题刷新；会话刷新同时更新已打开的话题。加载更多、点击图片和引用详情仍可按需读取，图片进入可视区不自动下载。发送、上传、撤回正常工作，但完成后不附带消息刷新；页面显示「仅手动刷新」，不显示为实时同步。

开机自启读取与修改使用固定的 `settings:get-startup` / `settings:set-startup` IPC，仅允许主窗口的本地应用页面调用。聊天历史仍只缓存在内存中。

## 抖音收藏监听

桌面端支持多个独立监听任务，每个任务拥有独立窗口、调度周期、显示策略和启动/停止开关；使用相同浏览器身份（partition）的任务共享抖音登录态，不同身份相互隔离。

- 在「运行设置」管理身份和新任务默认值；默认短间隔 10 秒、长间隔 60 秒、连续无变化阈值 3 次，默认值修改不影响已有任务。
- 每任务配置收藏页、收藏接口基础路径、完整请求 URL 包含筛选和 `clickText`，可选择只刷新不点击、后台隐藏、点击失败显示及停止后销毁窗口。
- URL 字段支持输入、历史选择和删除非默认历史项；执行中匹配的 fetch/XHR 响应会继续捕获。
- 提取 `aweme_list[].aweme_id` 后提交 `/api/douyin/aweme-records`；server 按 `(user_id, click_text, aweme_id)` 去重，只有真正新增项触发对应分组的飞书订阅，不补发库存。

完整任务配置、调度和异常交互见[监听产品规格](../../product-spec/douyin/monitor.md)，入库和分发规则见[分发规格](../../product-spec/douyin/library-and-delivery.md)。

## 扫码创建飞书 bot

推荐使用“扫码创建并绑定”：

- 选择 `feishu` 或 `lark` 域名。
- 点击“扫码创建并绑定”。
- 客户端展示扫码链接并自动轮询授权结果。
- 授权成功后，服务端会自动保存新 bot，并启动对应长连接。
- 如果授权后长连接正常但收不到消息，需要到飞书开放平台确认模板是否已经完成机器人能力、长连接事件订阅、消息事件和权限发布。

## 手动绑定飞书 bot

创建 bot 绑定时需要填写：

- 名称：本地展示名称。
- 域名：`feishu` 或 `lark`。
- App ID：飞书开放平台应用的 App ID。
- App Secret：飞书开放平台应用的 App Secret。
- Verification Token：可选，用于 webhook 校验。
- Encrypt Key：可选，预留给加密事件。

绑定成功后，服务端会为该 bot 启动独立飞书 WebSocket 长连接。

手动绑定已有应用前，请先在飞书开放平台完成配置：

- 开启机器人能力。
- 开通接收单聊消息、接收群聊中 @ 机器人消息、以机器人身份发消息等权限。
- 在事件订阅中选择长连接模式。
- 添加 `im.message.receive_v1` 事件。
- 发布应用版本。

## 注意事项

- 客户端负责绑定管理和群聊界面，通过 server 访问飞书，不直接持有应用凭证。
- 所有飞书事件处理都在服务端完成。
- 删除 bot 绑定后，服务端会关闭对应 bot 的长连接。
- 抖音监听依赖本机 Electron 会话和页面内 hook；如果长期收不到接口返回，优先检查 Douyin 窗口是否登录、任务的 `collectListUrl` 和请求 URL 筛选字符串是否匹配实际请求。

## 飞书群聊工作区

主窗口使用 32px 标题栏。Windows/Linux 移除原生标题栏与窗口菜单，右上角使用自定义最小化、最大化/还原、关闭按钮，最小化和关闭隐藏到托盘。macOS 采用 `titleBarStyle: 'hidden'` 保留左上角原生红黄绿按钮，并为其预留空间，黄色按钮最小化到 Dock，绿色按钮保留系统全屏行为；系统菜单保留应用、编辑和窗口功能及标准快捷键。拖动顶部空白区域移动窗口，双击遵循平台的窗口行为；点击托盘或 macOS Dock 图标恢复，真正退出使用托盘菜单「退出」或 macOS 应用菜单。`F12` 仍可打开开发者工具，登录页与各工作区共用窗口操作。

工作区采用左侧导航、群聊列表和会话内容三栏布局，聊天区占满窗口高度。长群名单行省略，已访问会话显示最近消息摘要；消息带发送者头像，当前机器人发出的消息靠右显示，连续消息合并间距。

鼠标悬浮或键盘聚焦消息时，在气泡外侧展示操作与时间：右侧气泡放在左边，左侧气泡放在右边，连续消息也可查看各自时间。发送者名字不再为隐藏时间预留空白。窄窗口和话题内为操作区预留宽度，避免越界；复制成功显示勾选反馈。`FeishuChatPanel` 的 `ownMessageAlignment` 参数支持 `'left' | 'right'`（默认右侧），由设置页面控制；身份判断、气泡颜色和撤回权限与位置独立。

自己消息的悬浮操作提供「撤回」，首次点击弹出二次确认；勾选「5 分钟内不再提醒」并成功撤回后，当前登录会话在 5 分钟内直接执行撤回，到期自动恢复确认。免提醒仅存在内存，切换服务端或登录凭证后清空，不保存消息数据。撤回成功会同步到主聊天、话题、引用详情和其他在线客户端，并释放图片缓存；失败时保留原内容并显示错误，不自动重试。撤回时限遵循企业管理员配置，详见 [飞书撤回消息](https://open.feishu.cn/document/server-docs/im-v1/message/delete)。

引用回复会聚焦对应输入框，`Esc` 取消引用，`Enter` 发送，`Shift+Enter` 换行，并兼容中文输入法确认。

主聊天和话题使用独立输入区：打开话题不会改变主聊天输入框的发送目标；话题面板在较窄窗口内覆盖会话右侧，保留独立的发送按钮。

登录后点击「群聊」并选择机器人；自动收取模式下选择群即可读取历史，「从不自动收取」则先刷新群列表、选择群后再手动刷新消息。支持向上加载历史、查看话题、文本与图片发送、引用/话题回复、复制文本和图片预览；发送身份始终是所选机器人。图片可选择、粘贴或拖拽，最大 10 MiB，图片和文字分别发送。

- 内存缓存跨机器人合计最近访问的 10 个群，后台新消息不改变访问顺序。
- 每群主线、话题、引用详情合计最多 300 条历史实体；待发送动作最多 3 个，单独展示。
- 消息缓存估算预算共 16 MiB，图片 Blob 预算共 16 MiB。浏览更早历史时会释放离开视图的页，仍可通过飞书重新加载。
- 断线恢复后校准当前最新页；阅读旧历史时用「返回最新」重建窗口，不把中间有缺口的两段消息直接拼接。
- 消息、草稿和图片不会保存到 localStorage、IndexedDB 或文件。窗口隐藏到托盘时内存仍在；退出账号、重载 renderer 或真正退出应用后清空。
- 未支持的消息类型显示摘要；卡片提供文本/成员列表摘要，不运行第三方卡片按钮。没有离线查看、关键词搜索、个人飞书身份发送或脱机发送队列。
- 若提示“发送结果待确认”，先刷新最新消息，再决定是否使用同一发送编号重试，避免不确定结果的重复发送。
