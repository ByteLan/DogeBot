# 飞书群聊工作台

## 目标与布局

在 desktop 中查阅所选机器人可访问的群和历史，以该机器人身份发送及回复。采用紧凑的飞书式布局：左侧全局导航、群聊列表、中间聊天内容；话题在右侧独立面板展开，窄窗口覆盖会话右侧。

- 机器人可切换；群列表分页加载，已访问群可显示缓存的最近消息摘要。列表与聊天顶部使用同一群头像及回退规则，长群名单行省略。
- 主聊天和话题分别保留输入框、历史翻页、阅读位置与发送目标；打开话题不会把主输入框改成话题发送。
- 历史来源为飞书主动查询，实时变化通过 server 长连接转 SSE。不是从本地归档回放，也不保证读取到机器人权限范围以外的历史。

## 消息展示与操作

| 能力 | 交互规格 |
| --- | --- |
| 消息阅读 | 显示发送者、头像、内容；连续消息压缩间距。向上加载旧页，阅读旧历史时保留位置，新消息通过提示引导返回最新 |
| 自己的消息 | “自己”指当前机器人；默认气泡靠右，可在设置改为靠左，主线与话题同时生效，身份与权限不随位置改变 |
| 悬浮操作 | 悬浮或键盘聚焦消息后展示引用、复制、话题、撤回等适用动作及时间。操作区位于气泡相反侧：右气泡在左、左气泡在右；名字不为隐藏时间留空 |
| 引用与话题 | 引用后聚焦目标输入框；可查看引用原文、发起话题回复或打开已有话题。取消引用不清空草稿 |
| 图片及其他内容 | 图片按需加载，可预览。富文本/卡片显示可读摘要；不支持的类型给出摘要，不运行第三方卡片交互按钮 |
| 复制 | 可复制消息文本/摘要，成功给出短暂勾选反馈；纯图片消息没有文本复制入口 |

## 发送与撤回

- 文本长度为 1–4000；`Enter` 发送、`Shift+Enter` 换行，中文输入法确认不触发发送；`Esc` 取消当前引用。
- 支持选择、粘贴和拖拽 PNG/JPEG/WebP/GIF 图片，单图最大 10 MiB。图片和文字分别发送，不将两次写入视作原子操作。
- 每会话待发送动作上限 3 个。明确展示发送中、失败、结果待确认；不确定结果先刷新核对，手动重试沿用同一发送 UUID，禁止自动重发造成重复。
- 当前机器人自己的消息提供撤回。默认二次确认；勾选「5 分钟内不再提醒」后，仅在成功撤回后启用本登录会话内的免确认期，到期或换账号/服务端恢复确认。
- server 执行撤回前重新读取消息，核对归属、群及发送者。撤回时限遵循企业配置；失败保留原内容并反馈原因，成功同步主线、话题、引用详情及其他在线客户端。

## 异常与范围

401 退出当前登录会话；网络或频控失败保留已缓存内容并允许重试；明确无权限或已移除时反馈不可访问。不能因群列表尚未翻到某群或临时网络失败就判定退群。过期缓存中的引用、话题、撤回目标按需查询确认。

当前没有离线查看、聊天消息关键词搜索、个人飞书身份发送、文件/语音发送、已读回执、精确未读数或脱机发送队列。抖音标题搜索是另一模块的功能，不属于聊天搜索。
