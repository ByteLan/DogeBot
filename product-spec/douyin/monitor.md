# 收藏监听与浏览器身份

## 页面与任务

入口：desktop「抖音监控」。顶部提供新增任务、开始全部、停止全部和运行状态；「运行设置」内管理浏览器身份及新任务默认值。每个任务可独立开始、停止、立即刷新、显示/隐藏窗口并查看运行事件。

每任务拥有独立窗口和调度器，可同时运行多个任务；当前不是多个任务共享同一窗口串行执行。浏览器身份（partition）决定登录态：同身份的任务共享登录，不同身份隔离；默认身份沿用 `persist:dogebot-douyin`，可新增身份并分别登录，默认身份不能删除。

删除自定义身份会把引用它的任务配置改为默认身份；此操作移除身份配置，不清除原 partition 在磁盘上的登录数据。

## 配置规格

| 字段 | 规则与默认值 |
| --- | --- |
| 启用、浏览器身份 | 新任务启用，默认使用内置身份；“开始全部”使用启用的任务 |
| 收藏页 URL | 每轮打开的页面，默认指向自己的收藏页；支持输入及历史选择 |
| 收藏接口 URL | 按 `origin + pathname` 匹配，默认收藏视频列表接口；支持历史选择 |
| 请求 URL 筛选 | 对完整请求 URL 做包含匹配，通常填写收藏集参数；内置示例需按实际目标配置 |
| 点击文案 `clickText` | 用于页面点击及服务端入库分组；不点击模式也需明确业务分组 |
| 不点击，仅刷新 | 默认关闭；开启后仍打开页面并监听匹配接口 |
| 短间隔 / 长间隔 | 默认 10 秒 / 60 秒；每任务独立 |
| 连续无变化阈值 | 默认 3 次，达到后改用长间隔；收到变化后回到短间隔 |
| 后台隐藏 / 点击失败显示 | 均默认关闭，可按任务设置 |
| 停止后销毁窗口 | 默认开启；删除任务强制销毁其窗口与运行状态 |

顶部默认值只影响之后新增任务，不批量修改已有任务；旧配置按兼容规则补齐。任务、身份列表、默认值及输入历史保存于当前设备。URL 相关历史在开始任务时记录，可删除非默认历史项。

## 执行与反馈

- 每轮打开目标页，等待页面就绪，再按配置点击；当前页面就绪等待、接口捕获等待、轮后暂停各为 5 秒，之后按当前间隔调度。
- 使用页面 fetch/XHR hook 观察响应，不阻塞原请求；匹配基础接口和筛选条件后解析 `aweme_list[].aweme_id`。监听运行期间的匹配响应也可捕获。
- 显示运行/停止、短/长周期、连续无变化次数、下次执行时间、窗口状态、点击和同步结果。点击失败可按任务设置弹出窗口以便检查。
- 捕获失败、页面/登录失效或网络错误应反馈当前任务问题，不能因此删除 server 已有视频。没有持久化的离线上传队列，不能承诺失败期间的数据必定补传。
- 停止解除定时与捕获等待；是否保留窗口遵循任务选项，浏览器持久登录态不因关闭任务窗口清空。

验收关注：多任务互不阻塞、partition 登录隔离/共享、匹配筛选、短长周期切换、停止/删除时窗口回收、新任务默认值不修改旧任务、上传失败提示。
