# 设备设置

入口：左侧「设置」，位于「抖音监控」下方。按「常规」「聊天」分组，使用 Arco Card、Switch、Radio 等组件；修改即时生效并自动保存，无额外提交按钮，仅作用于当前设备，不同步至其他客户端。

| 分组 / 设置 | 默认 | 行为与保存方式 |
| --- | --- | --- |
| 常规 / 开机自启 | 关闭（以已有系统状态为准） | Windows/macOS 安装版通过系统登录项读写；界面显示系统实际状态，已有系统配置优先，不以本地布尔值覆盖 |
| 聊天 / 自己发出的消息气泡 | 右侧 | 可选左/右，保存 `dogebot.ownMessageAlignment`；主线和话题即时调整，非法值回落右侧 |
| 聊天 / 消息收取方式 | 始终收取 | 可选始终/仅查看群聊时；保存 `dogebot.chatReceiveMode`；缺失或非法值回落始终收取 |

## 开机自启

- 开发模式和不支持的系统禁用开关并说明原因，不注册开发版 Electron 为启动项。
- 开关读取、保存时展示加载状态；失败显示原因及重试，不能在系统未应用时显示成功。
- Windows 读取系统是否允许该程序登录启动，反映任务管理器中禁用启动项的结果；macOS 需要用户批准时提示到系统设置允许。
- 不新增“启动到托盘”等尚未实现的选项；首次使用不主动修改操作系统已有设置。

## 聊天设置

气泡排列只改变布局，不改变当前机器人的身份、颜色或撤回资格。操作及时间始终放在气泡相反侧，切换不清除草稿、话题和缓存，见[群聊交互](../chat/README.md)。

收取模式控制订阅及读取生命周期，完整判定、暂停保留和恢复规则由[消息收取规格](../chat/message-receiving.md)维护。不要将“窗口失焦”解释为“离开群聊”，也不要将暂停操作复用为退出会话。

验收关注：默认值和非法配置、刷新后偏好恢复、左右布局即时更新、系统启动项真实读写、权限/平台不可用状态、模式切换时草稿不丢失。
