# 被动互动与短期上下文

## 能力与默认值

普通消息在未被命令或兜底处理后，可按会话设置和概率触发互动。bot 被动总开关默认开启；以下为未配置环境变量和会话覆盖时的值。

| 能力 | 命令 | 默认开关 / 概率 |
| --- | --- | --- |
| 给消息贴表情 | `/reaction` | 开 / 10% |
| 文本复读 | `/repeat` | 开 / 5%；默认最长 300 字符 |
| 大模型接话 | `/llm-reply` | 开 / 5%；还需配置模型接口、Key、模型名，@ bot 的消息不参与该概率接话 |
| 图片/表情包复读 | `/media-repeat` | 关 / 0% |
| 图片镜像 | `/image-reverse` | 开 / 5% |
| 表情包镜像 | `/sticker-reverse` | 开 / 20% |
| 字节范随机生图 | `/byte-style` / `/字节范` | 开 / 5% |
| 勇攀高峰随机生图 | `/scale-new-heights` / `/勇攀高峰` | 开 / 5% |

会话命令支持 `--enable`、`--disable`、`--rate`；无修改参数时查询状态。概率支持小数或百分数写法，实际值限制在 0–100%，会话设置上限为全局默认值的 10 倍（且不超过 100%）。因此默认概率为 0 的能力，单独开关不能提升其触发概率，需要先配置全局基准。

贴纸另支持 `--max`：默认仅对不超过 10 字符的文本随机生图，绝对上限默认 150；详情见[贴纸](../stickers/README.md)。同一消息同时命中文本复读与贴纸时只选择其中一种；其他独立互动可并行，不能承诺每条消息只产生一个动作。

## 消息位置与失败

话题内触发的文本/图片回复留在话题内，否则发送到当前会话。媒体解析、模型请求和镜像转换失败应隔离记录，不让某一互动失败阻止其他互动。手动镜像命令不依赖随机开关，但仍需要可读取的媒体目标和 Python/Pillow 运行环境。

## 数据生命周期

- server 以 bot + 会话维护最多 30 条近期文字的进程内上下文；大模型默认使用最近 8 条。它不是可查询历史归档，进程重启后不保留。
- 图片/表情包处理复用独立临时媒体缓存：资源必须小于配置上限，默认 4 MiB；原始文件缓存命中会续期，3 天未命中后清理，默认每小时扫描。
- 镜像处理文件位于独立临时目录，发送后清理；该临时文件机制与 desktop 聊天图片的内存缓存不同。
- 模型请求会使用配置的外部接口和近期文本，未配置时不能承诺接话可用。当前没有 desktop 上下文浏览或聊天历史搜索入口。

验收关注：bot 总开关、各会话隔离、默认概率和上限、文本复读/贴纸互斥、话题位置、媒体大小与清理、外部请求失败隔离。
