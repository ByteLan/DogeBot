# 机器人命令与会话管理

## 触发与身份

飞书私聊文本、或群内 @ 当前机器人的文本进入命令解析；普通群消息可进入被动互动。当前 bot 自己发送的消息不再次触发自身业务；重复事件去重。历史查询不触发命令。

DogeBot 绑定账号负责库存与应用归属，飞书用户身份负责命令管理员及个人 @ 列表；不能混用这两个身份。

## 命令与交互

| 命令/入口 | 规格 |
| --- | --- |
| `/help` | 交互卡片导航命令、会话设置与任务，按卡片入口查询/提交/确认；desktop 对卡片只展示摘要，操作需在飞书完成 |
| `/users [@成员]` | 按 bot + 发起人记录 @ 关系，返回其历史成员列表；无成员参数只查询 |
| `/users delete [@成员]` | 软删除当前发起人的全部或指定关系 |
| `/users top @成员` / `/users new n` | 置顶成员或只显示最近新增成员；列表及文本卡片在数量较大时分块展示 |
| `/users --copy-from @成员` | 发送仅展示来源有效名单数量的确认卡片，只有命令发起人能撤回或确认；确认后合并到自己的名单 |
| `/douyin ...` | 库存抽取、标题搜索、订阅及管理员删除，见[抖音分发](../douyin/library-and-delivery.md) |
| `/set-default "指令"` | 设置 bot 兜底；首次设置者成为管理员，此后只有其可修改。未命中命令时执行兜底；无法解析的兜底按文本回复，不递归修改配置 |
| `/admin [--passive-enable\|--passive-disable]` | 仅管理员私聊可用，查询或切换 bot 被动互动总开关 |
| `/reverse` / `/反转` | 处理当前首图或引用图片/表情包，随机选择轴向与方向镜像；无目标或处理失败明确提示 |
| `/revert` / `/撤回` | 引用消息或在 bot 发起的话题中操作；查询目标并检查当前会话及 bot 发送者，再请求飞书撤回 |
| 贴纸命令 | 手动文案、引用生图及交互卡片，见[贴纸规格](../stickers/README.md) |
| 会话能力开关 | `--enable` / `--disable` / `--rate` 等按 bot + 会话配置，见[被动互动](passive.md) |

`/users` 的成员列表与 Markdown 卡片保留现有分开发送/话题展示策略，不将两种展示合成一条消息。引用和原消息关系应保留，不能因 UI 整理改变飞书侧回复位置。

### 复制个人 @ 名单

- 私聊使用 `/users --copy-from @成员`，群内需同时 @ 当前 bot。`--copy-from` 后必须是一个真实的飞书人员 mention；不接受手写姓名、@所有人、当前 bot、自己或多个来源，也不能混用 `delete`、`top`、`new` 等参数。无效用法只提示，不变更名单。
- 在原命令的回复位置发送确认卡片，正文只显示来源有效名单的数量，不显示人员姓名、ID、头像或 @ 标签。卡片包含「撤回」「确认」两个按钮，注明仅触发人可操作。
- 触发命令时不添加来源成员，也不修改触发人的名单。点击任何按钮均按服务端保存的请求核对 bot、会话、卡片消息及点击者的飞书 ID；其他人或缺少身份的回调不能撤回卡片或修改记录。
- 「撤回」取消请求并撤回该确认卡片，不修改名单。「确认」从数据库读取来源在同一 bot 下当前未软删除的全部关系，合并到触发人的记录；保留触发人原有成员及置顶顺序，重复关系去重，触发人已软删除的对应关系恢复。来源名单不变，来源置顶和时间信息不复制。卡片展示发起时的预览数量，来源之后可能修改名单；实际复制以确认时的有效名单为准，空名单也可确认。
- 确认结果卡片只显示有效来源人数及新增/恢复人数，不发送具体人员名单；需要查看时由触发人另发 `/users`。数据库中的请求状态与名单写入在同一事务中完成，重复回调和服务重启不会重复复制；卡片更新或撤回失败记录错误，后续同按钮回调可重试展示操作。删除 bot 绑定时同时删除其复制请求。

## 定时任务

- `/add-cron "表达式" "指令"` 绑定当前 bot 和聊天会话；省略指令时使用已配置的默认兜底，没有兜底则提示补充。
- `/add-cron --list` 列出当前会话任务；`--delete 序号` 按最新列表序号删除，不跨会话删除。
- 使用 5 段 cron（分、时、日、月、周），支持通配、列表、范围与步长。时间按 server 本机时区解释；默认每 30 秒扫描，不是秒级定时。
- 当前任务执行只支持 `/douyin`。不支持的指令给予提示，不承诺任意命令调度；删除机器人绑定时删除相关任务。

## 边界与反馈

未识别文本且没有兜底时进入既有被动互动，不保证逐条回复。原有 [bot-command.md](../../bot-command.md) 仅覆盖部分基础命令，完整行为以本模块及源码核对。参数冲突、无权限、无目标、第三方失败应给出适当反馈；管理员通知错误不得中断其他业务。

验收关注：私聊/群 @ 触发、普通群消息与自己消息不误执行命令、管理员认领/清除、会话任务隔离、无兜底及无效参数、引用撤回目标确认，以及名单复制的隐私展示、触发人权限、同 bot 隔离、软删除恢复和重复确认。
