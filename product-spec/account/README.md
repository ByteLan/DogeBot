# 账号与登录

## 功能与入口

desktop 登录页填写服务端 URL、用户名和密码。默认服务端为 `http://127.0.0.1:3000`；账号由维护者在 server 目录通过 `pnpm add-user <用户名> <密码>` 创建，当前没有自助注册、找回密码或账号管理页面。

## 产品规则

- 登录成功进入工作区，后续请求使用 Bearer token；`GET /api/me` 用于确认当前登录用户。
- 用户只能列出和管理自己绑定的机器人，聊天接口进一步校验机器人归属、启用状态和目标群/消息。抖音入库记录按登录用户归属保存。
- 登录会话有效期为 7 天；请求鉴权成功且剩余不足 3 天时续期至 7 天。兼容旧格式 token；没有使用中的会话可能过期。
- desktop 在本机保存 server URL 和 token；密码不持久化。401 需要重新登录，错误反馈与普通网络失败区分。
- 退出登录清除本机 token，销毁聊天会话及其内存数据；当前没有服务端登出/撤销全部 token 的 API，不能将本地退出描述为服务端凭证立即作废。
- 本地聊天显示偏好和抖音任务配置属于设备设置，退出登录不会重置这些配置。

## 数据与验收

server SQLite 保存用户、密码派生哈希及登录会话；机器人凭证只由服务端管理。聊天消息的数据边界见[聊天数据生命周期](../chat/data-lifecycle.md)。公开 OpenAPI 与健康检查不属于登录后用户接口，其用途见[抖音分发](../douyin/library-and-delivery.md)和[贴纸](../stickers/README.md)。

验收关注：正确/错误凭证、重启后恢复登录、会话过期、跨用户机器人不可访问、退出及账号切换后旧聊天请求不能污染新会话。
